# Database schema plan

Source: `db.zip/db/src/schema/` (55 models, 543 fields, 38 enums). The `src.zip` Prisma 8 example sets the contract style. This is a new database design, not a copy of the old physical schema.

## Package structure

```text
packages/database/
├── SCHEMA_PLAN.md
├── prisma.config.ts
└── src/prisma/
    ├── contract.prisma  # models, fields, relations, and enums
    ├── contract.json    # generated by Prisma
    ├── contract.d.ts    # generated by Prisma
    └── db.ts            # existing client
```

Prisma 8 reads one contract source, so the old Drizzle schema files become model blocks in `contract.prisma`. Prisma's model and field names define the new database names. The old `@map` and `@@map` names, named indexes, custom checks, and duplicate composite foreign keys are not part of this design.

## Steps

1. Inventory every source model, enum, and field.
2. Replace the empty TypeScript contract with a Prisma 8 PSL contract. Keep field types, required/optional status, useful defaults, primary keys, direct relations, and ordinary uniqueness where it defines record identity.
3. Point `prisma.config.ts` at `contract.prisma` and emit `contract.json` and `contract.d.ts`.
4. Compare the resulting contract with the source inventory, then run the package's type and lint checks. No database connection or migration is part of this schema-only change.
