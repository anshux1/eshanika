# 06 Media

**Goal:** upload product images to IDrive e2 and arrange them on products.

## Build

- `lib/idrive-e2.ts` with an S3 client for the bucket's regional endpoint. `app/api/upload/route.ts` with Better Upload: admin-only, images only (jpeg, png, webp, avif), 10 MB limit.
- The browser uploads directly with a signed URL. Then `catalog.media.create` saves the `MediaAsset` (key, name, type, size, width, height).
- `/media`: grid library with search, alt text editing, archive, and "used by" products.
- Product media picker on `/products/[id]`: dropzone, pick from library, drag to reorder, set one primary image, remove.

## Rules

- Credentials stay on the server. Storage keys are generated by the server.
- Archiving is blocked while an active product uses the image.
- Publishing a product requires alt text on its primary image.

## Done when

- An image uploaded from the product page appears in the library, and the product shows the new primary image.
- A 20 MB file and a PDF are both rejected with clear messages.
